# Pôle Assala — AI image prompts for the formations (v2 — richer posts)

Works in **ChatGPT** (image generation) and **Gemini** (image generation).

Each formation has:

- **A — Full feed post (4:5)**: photo + title + 4 programme points + trainer + call to action
- **B — Carousel (3 slides, 4:5)**: 1 cover · 2 programme · 3 trainer + inscription
- **C — Story (9:16)**: photo + title + 3 key points + call-to-action button
- **Caption** in French, ready to paste

---

## Tips for posts with more text

1. **Generate one image per message.** For the carousel, send slide 1, then slide 2 in the same chat ("same style as before"), then slide 3 — the style stays consistent.
2. **Check every word.** More text = more risk of a wrong accent. If one is wrong, reply:
   *"Keep the image exactly identical, only fix this text so it reads exactly: …"*
3. **ChatGPT is usually more accurate with long French text; Gemini is often better for the photo.** Good trick: make the photo in Gemini, then upload it to ChatGPT and say *"Use this photo and add the layout and text below"* + the prompt.
4. **Replace the `[…]` placeholders** (date, price, WhatsApp number) before generating, or delete that line from the prompt.
5. If it looks crowded, reply: *"Same content, more white space, smaller programme text."*
6. If it looks "too AI", reply: *"Make the photo look like a real editorial photograph: natural skin texture, muted colours, no glow."*

### Shared style (already inside every prompt)

Real-photo realism, soft natural light, muted colours. Thin terracotta lines or small numbered markers as the only decoration.
